## 当前限制

这是可联调的P0后端，尚不是生产部署验收。单工作区写入串行化用于保证提交顺序；大数据量列表过滤、快照生成与级联删除需要后续优化。墓碑、幂等记录和未使用文件当前不做自动清理。多实例需要共享私有文件存储或对象存储适配。上传续签、类型不符和签名到期分支还需增加专门测试，生产部署另需数据库TLS、HTTPS及备份恢复验证。
