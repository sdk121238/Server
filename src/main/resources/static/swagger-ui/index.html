使用说明
开始调试

先选择“账号密码登录”，填写 API 账号密码并执行。将返回的 accessToken 粘贴到 Authorize，只填令牌本身。

患者仅访问自己账号的数据；医生可查看全部患者，scope=mine查看主治名下患者。选择主治医师前先查询“医生”列表。年龄自动计算，无需填写。

修改或删除前先查询详情，把响应头 ETag（含双引号）填入 If-Match。新业务更换 Idempotency-Key，网络重试保留原键和正文。

图片流程：患者 → 病灶 → 上传会话 → 图片 PUT → complete → 采集。
